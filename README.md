# Подбор офиса — Ереван

Статическое веб-приложение на русском языке для сбора и сравнения вариантов коммерческой аренды.

## GitHub Pages
Workflow из `.github/workflows/pages.yml` автоматически публикует сайт при push в `main` или вручную через Actions → Deploy static site to GitHub Pages → Run workflow.

Публичный адрес: https://smolvicjj.github.io/office-selection-app/

Если публикация завершается ошибкой из-за отключённых Pages, откройте Settings → Pages и включите публикацию через GitHub Actions. Для приватного/ограниченного аккаунта или организации может понадобиться разрешение владельца репозитория.

## Возможности
- Главная панель и пять демонстрационных помещений в Ереване.
- Добавление помещения вручную или заполнение полей из вставленного текста объявления.
- Фильтры и сортировки по статусу, рейтингу, цене и площади.
- Автоматическая оценка с настраиваемыми весами.
- Комментарии с автором и временем.
- Сравнение двух или трёх вариантов и рекомендация по оценкам.
- Данные сохраняются в localStorage браузера.

## Ограничения
Это статическое приложение: данные хранятся отдельно в браузере каждого пользователя. Для общего доступа между устройствами нужен backend/database. Извлечение объявления напрямую с List.am/MyRealty может быть ограничено CORS; вставка текста — рабочая альтернатива.
